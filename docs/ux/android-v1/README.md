# ORUN Android UX v1 — Tasarım ve etkileşimli prototip

**Durum:** Tasarım taslağı / örnek kullanıcı arayüzü; **APK veya üretim kodu değildir.**

Bu dizin, mevcut `edge/app` uygulamasını ve haberleşme sistemini değiştirmeden Android ürün deneyimini incelemek için oluşturuldu.

- [UX v1.0 tasarım belgesi](ORUN_ANDROID_UX_V1_TASARIM.md): bilgi mimarisi, ilk kurulum, ekran sözleşmeleri, çevrimdışı senaryolar, güvenlik sınırları ve kabul ölçütleri.
- [Etkileşimli HTML prototip](orun_android_ui_prototip.html): beş ana sekme, örnek hayvan/cihaz durumları ve kurulum akışı. Dosyayı indirip tarayıcıda açarak çalıştırabilirsiniz.

**Sınırlar:** Tüm bilgiler örnektir. HTML, gerçek Bluetooth/LoRa bağlantısı, cihaz yetkilendirmesi, kayıt aktarımı veya sunucu API işlemleri gerçekleştirmez. Çalışan Android uygulaması `edge/app` altında kalır. Üretim güvenliği ve cihaz yapılandırma yetkileri ilgili mimari inceleme ve fiziksel doğrulamalara tabidir.

Referanslar: [PRD](../../../PRD.md), [ürün/sistem mimarisi](../../architecture/ORUN_PRODUCT_SYSTEM_ARCHITECTURE.md), [güvenlik adım 3](../../architecture/ORUN_STEP3_REAL_SECURITY_PLAN.md).
