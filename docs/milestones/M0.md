# M0 — PlatformIO firmware foundation

## Objective

Provide one minimal Arduino firmware foundation for RAK4630/RAK4631 hardware
that builds with PlatformIO and emits a USB Serial boot banner at 115200 baud.

## Changed files

- `.gitignore` — excludes PlatformIO build output, IDE/temporary files, and
  local secret files without excluding `firmware/rakwireless` vendor files.
- `firmware/platformio.ini` — selects the vendor-provided `rak4630` board and
  RAK4630 variant sources.
- `firmware/include/firmware_version.h` — central firmware version constant.
- `firmware/src/main.cpp` — minimal USB Serial boot banner.

## Build command

```sh
cd firmware
pio run
```

## Build result

`pio run` completed successfully for `rak4630` using PlatformIO Nordic nRF52
platform 11.0.0 and Arduino framework 1.7.0.

- RAM: 8,740 bytes / 248,832 bytes (3.5%)
- Flash: 52,732 bytes / 815,104 bytes (6.5%)

## Not yet verified on physical hardware

- USB enumeration and the availability of the serial port.
- The boot banner at 115200 baud, including the generated build date/time.
- Upload and reset behavior on RAK4630 and RAK4631 hardware.
